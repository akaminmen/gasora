# Logos de marcas

Esta carpeta contiene los logos que se muestran como icono de la estación (tarjetas de resultado, ficha y favoritos). Son marcas de sus respectivos propietarios y se usan solo para identificar la estación; Gasora no está afiliada a ellas. **Estos archivos no están bajo la licencia MIT del repositorio.**

Un archivo por marca, con el nombre de la tabla de `src/lib/brand-logos.ts`: `<nombre>.svg` o, si no hay SVG, `<nombre>.webp` o `<nombre>.png`. Si falta el archivo, la interfaz muestra el avatar con la inicial. Valida la carpeta con `npm run brands:check`.
